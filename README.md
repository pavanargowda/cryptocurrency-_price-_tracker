Cryptocurrency Price Tracker

📌 About the Project

Cryptocurrency Price Tracker is a Python-based mini project that fetches and displays the latest prices of the top 10 cryptocurrencies using the CoinGecko API. It displays cryptocurrency names, symbols, current prices, market capitalization, and trading volume. It also stores price history in an SQLite database and allows users to refresh prices and view previous records through a simple terminal-based interface.

✨ Features

- Displays top 10 cryptocurrencies.
- Fetches updated cryptocurrency prices.
- Shows current price in USD.
- Displays market capitalization and trading volume.
- Stores price history in SQLite database.
- Allows users to view previous price records.
- Simple menu-driven interface.

🛠️ Technologies Used

- Python
- SQLite Database
- CoinGecko API
- Requests Library

⚙️ Installation and Setup

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Open the project folder

cd cryptocurrency_price_tracker

3. Install dependencies

pip install -r requirements.txt

4. Run the project

python main.py

📋 Application Menu

1. Refresh Prices – Fetch the latest cryptocurrency prices.
2. View Price History – Display previously stored price records.
3. Exit – Close the application.
